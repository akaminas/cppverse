## What it is

Three small features, all introduced in C++11 or C++17, that make code using the standard library much shorter and easier to read:

- **`auto`** lets the compiler deduce a variable's type from its initial value: `auto it = nests.find("DUNE-04");` instead of `std::map<std::string, int>::iterator it = …`.
- **Type aliases** give an existing type a new, shorter name: `using Trajectory = std::vector<double>;`.
- **Range-based `for`** visits every element of a container directly: `for (double N : trajectory) { … }`.

None of them changes what a program can do. All three remove noise, so that what remains is the part a reader needs to check.

## Why it matters

Model code combines containers: a map from site codes to vectors of counts, a vector of (time, state) pairs, a list of individuals. Their full type names quickly become longer than the logic around them, and a loop over one by iterator spells the type three times. Long names also hide mistakes. The most common is copying every element of a large container on each pass through a loop, or silently modifying a copy and then wondering why the population never changed. The loop-variable rules in this lesson make those choices visible.

## How it works in C++

### auto

A variable declared `auto` takes the type of its initialiser:

```cpp
auto n = 0;                          // int
auto r = 0.5;                        // double
auto steps = trajectory.size();      // std::size_t
auto it = nests.find("DUNE-04");     // std::map<std::string, int>::iterator
const auto mean = total / count;     // const, with the type of total / count
```

Three rules cover almost every case:

1. **The type comes from the initialiser, so there must be one.** `auto x;` does not compile, which is a small bonus: an `auto` variable is never uninitialised.
2. **Literals decide.** `auto total = 0;` makes an `int`. Adding doubles to it later truncates every sum to a whole number. Write `auto total = 0.0;`, or simply `double total = 0.0;`.
3. **Plain `auto` makes a copy.** It drops references and top-level `const`. If `best` is a reference to a large object, `auto x = best;` copies it; `const auto& x = best;` does not.

Use `auto` where the type is obvious from the right-hand side or irrelevant to the reader (iterators, results of `find`, elements in loops), and write the type when it carries meaning: `double survival = 0.9;` tells the reader more than `auto survival = 0.9;`.

### Type aliases

A *type alias* is a second name for an existing type. Two spellings exist:

```cpp
using Trajectory = std::vector<double>;          // modern
typedef std::vector<double> Trajectory;          // older, same meaning
using Matrix = std::vector<std::vector<double>>;
using SiteIter = std::map<std::string, int>::const_iterator;
```

Prefer `using`: it reads left to right like an assignment ("Trajectory is a vector of double"), and it also works for templates, which `typedef` cannot do: `template <typename T> using Series = std::vector<std::pair<double, T>>;`.

An alias is not a new type. A `Trajectory` *is* a `std::vector<double>`; you can pass one where the other is expected. Its value is documentation: `Trajectory simulate(const Parameters& p)` says what the function returns in the model's own terms.

### Range-for: copy, reference or const reference

A range-based `for` loop declares a loop variable that stands for each element in turn. How it is declared decides what the body can do:

| Declaration | The loop variable is | Use it when |
|---|---|---|
| `for (double m : masses)` | a **copy** of each element | the elements are cheap (numbers) and you only read them, or want to modify a local copy |
| `for (double& m : masses)` | a **reference** to each element | the body must change the elements |
| `for (const Individual& ind : population)` | a **const reference** | the elements are large and you only read them |
| `for (const auto& entry : container)` | a const reference, type deduced | the general read-only case |
| `for (auto& entry : container)` | a reference, type deduced | the general modifying case |

With `auto&` the names refer to the members inside the container, so `count += 1;` changes the map; with `const auto&` they are read-only. The binding order is the declaration order of the members: for a map entry, the key first and the value second.

### When you still need an index

A range-for has no index. When the body needs the position (to print the time step, to read a neighbouring element, or to fill two vectors in parallel), use a counting loop with `std::size_t`, as in <Concept id="std-vector" />. Do not add or remove elements of a container inside a range-for over it: the loop uses iterators internally, and `push_back` or `erase` can invalidate them (<Concept id="iterators" />).

## In biological modelling

- **Name the model's types.** `using State = std::vector<double>;`, `using Trajectory = std::vector<State>;` and `using ParameterSet = std::map<std::string, double>;` let function signatures describe the model: `Trajectory run(const ParameterSet& p, State start, int steps)`.
- **Update individuals by reference.** `for (auto& plant : population) { plant.height += growth(plant); }` changes the population; the same loop without `&` would silently change copies and leave the model unchanged.
- **Summarise by const reference.** Loops that compute totals, means or counts over individuals, patches or records should use `const auto&`.
- **Loop over parameter tables** with `for (const auto& [name, value] : parameters)` to print every parameter at the start of a run, so that the output file records exactly which values produced it.

## Common mistakes

- **Modifying a by-value loop variable** and expecting the container to change.
- **`auto total = 0;` for a sum of doubles.** It deduces `int`.
- **Copying large elements** with `for (auto x : big)` where `const auto& x` was meant.
- **Changing the size of the container inside a range-for** over it (`push_back`, `erase`).
- **Overusing `auto`.** `auto r = 0.5f;` (a `float`) or `auto n = v.size() - 1;` (an unsigned value that wraps when `v` is empty) hide information the reader needs. Spell out types that carry meaning.
